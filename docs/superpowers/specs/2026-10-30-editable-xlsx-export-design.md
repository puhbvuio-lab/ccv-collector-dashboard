# 可编辑 CCV Excel 导出设计

## 目标

直接增强看板现有“导出 Excel”功能，使下载文件既包含可追溯的逐次采样数据，也包含能在 Excel 中继续编辑的 CCV 趋势图，不引入独立报告流程。

## 导出结构

- `采样数据` 工作表：每行代表一个实际采样点，列为采样时间、直播链接、主播名称、直播标题、CCV、直播场次 ID。
- 采样时间使用 Excel 日期时间值显示，并明确为北京时间（UTC+8）。
- 直播链接按 Twitch 频道登录名生成 `https://www.twitch.tv/<channel>`，单元格设置为可点击超链接。
- 主播名称优先使用 Twitch `display_name`，缺失时回退为频道登录名。
- 直播标题使用该采样点保存的标题，允许同一直播中标题变化。
- `CCV趋势图` 工作表：按直播场次生成 Excel 原生折线图，每个场次一条曲线；图表引用工作簿内的数据单元格，因此标题、样式、坐标轴和数据范围均可在 Excel 中编辑。
- 图表横轴为北京时间采样时间，纵轴为 CCV；多场直播同时存在时用“主播名称 · 场次 ID”区分系列。

## 兼容与异常处理

- 优先读取完整单场 CSV，确保不受状态文件仅保留最近 2000 个点的限制。
- 旧数据缺少展示名或逐点标题时，从场次汇总信息回填；仍缺失则保留空值，不阻止导出。
- 无采样数据时仍生成带表头的有效工作簿和说明，不创建空图表。
- 保留现有导出 URL 和看板按钮，不改变用户操作方式。

## 实现选择

- 采用现有 `openpyxl` 导出路径，直接生成原生 Excel 图表。
- 不接入较重的 Node 完整报告流程，因为该流程生成更慢，且不适合看板随时下载。
- 不导出静态 PNG 图，因为无法满足“对应可编辑趋势图”的要求。

## 验收标准

- 导出文件可被 `openpyxl` 和 Excel 正常打开。
- 明细表包含要求的五项核心属性，并额外包含场次 ID 以区分多场直播。
- 链接为可点击的 Twitch HTTPS 地址。
- 有采样时至少生成一个原生折线图，数据系列引用对应场次的采样时间与 CCV。
- 现有任务导出接口及其他自动化测试保持通过。
